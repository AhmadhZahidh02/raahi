# raahi

## Ilma — Forever In My Heart ❤️

A romantic surprise website for Ilma.

### Features
- Cinematic dark burgundy, crimson, and black romantic theme
- Floating starlight and ambient hearts canvas
- Interactive glowing heartbeat button
- Splitting heart animation with glowing particle bursts
- Love message card with mobile screenshot and download support
- Client-side high-resolution love card export (HTML5 Canvas)
- Responsive, accessible, and supports reduced motion
